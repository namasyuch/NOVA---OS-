# NOVA OS
NOVA OS is my web-based operating system built for the Hack Club WebOS 1 mission.
I wanted to make a small desktop environment that runs in the browser, with simple apps and draggable windows.

## Features
* Custom NOVA desktop
* Draggable windows
* Desktop app icons
* App dock
* Live clock and date
* Notes app with saved notes
* Calculator
* 25-minute focus timer
* Projects section
* Notifications
* Escape key to close windows
* Responsive layout

## Built With
* HTML
* CSS
* JavaScript
* LocalStorage

## Extra Feature
The Notes app uses LocalStorage, so notes stay saved after refreshing the page.

## How to Use
Open the live website and click an app from the desktop or dock.
Windows can be moved by dragging their headers and closed using the × button.
The Notes app lets you create and save notes. The Calculator performs basic calculations, and the Focus app provides a 25-minute timer.
No account is required.

## Project
This project was built as part of Hack Club's WebOS 1 mission.

## AI Usage
During development, I used AI for some parts of the project. A reviewer pointed out that I was relying on AI too much.
After the feedback, I went back through the project and simplified the code, removed unnecessary comments and features, and worked on making more of the code my own.
I tested the changes myself and made the final design and project decisions.
