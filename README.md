# NOVA OS
NOVA OS is my own web-based operating system built for the Hack Club WebOS 1 mission.
I wanted to make something that feels like a small personal desktop environment while keeping the design and features my own.

## Features
* Custom NOVA desktop
* Draggable windows
* Desktop app icons
* App dock
* Live clock and date
* Notes app with saved notes
* Calculator
* 25-minute focus timer
* Projects section
* Dark/light mode
* Notifications
* Keyboard shortcut support
* Responsive layout

## Built With
* HTML
* CSS
* JavaScript
* LocalStorage

## Extra Feature
The Notes app uses LocalStorage, so notes stay saved even after refreshing the page.

## How to Use
Open the live website and click any app from the desktop or dock.
Windows can be dragged around using their headers and closed using the × button.
No account or password is required.
